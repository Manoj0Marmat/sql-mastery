## P1 — Department Headcount
**Concept:** COUNT + GROUP BY

```sql
SELECT Department, COUNT(1) AS NoOfEmp
FROM Employees
GROUP BY Department
ORDER BY NoOfEmp DESC
```

---

## P2 — High Headcount Departments
**Concept:** HAVING

```sql
SELECT Department, COUNT(1) AS NoOfEmp
FROM Employees
GROUP BY Department
HAVING COUNT(1) > 3
ORDER BY NoOfEmp DESC
```
**Key:** HAVING filters groups, WHERE filters rows. Aggregates not allowed in WHERE.

## P3 — Department Salary Summary
**Concept:** Multiple aggregates + DECIMAL precision

```sql
SELECT Department,
    COUNT(EmpID) AS TotalEmployees,
    SUM(Salary) AS TotalSalary,
    CAST(AVG(CAST(Salary AS DECIMAL(10,2))) AS DECIMAL(10,2)) AS AvgSalary,
    MAX(Salary) AS MaxSalary,
    MIN(Salary) AS MinSalary
FROM Employees
GROUP BY Department
ORDER BY AvgSalary DESC
```
**Key:** `AVG(salary)` on INT truncates. Wrap: `CAST(AVG(CAST(salary AS DECIMAL(10,2))) AS DECIMAL(10,2))`

## P4 — Selective Department Report
**Concept:** HAVING with multiple conditions

```sql
SELECT Department,
    COUNT(1) AS TotalEmployees,
    CAST(AVG(CAST(Salary AS DECIMAL(10,2))) AS DECIMAL(10,2)) AS AvgSalary
FROM Employees
GROUP BY Department
HAVING COUNT(1) > 2 AND AVG(Salary) > 80000
```

## P5 — Salary Band Count
**Concept:** CASE inside SUM

```sql
SELECT Department,
    COUNT(1) AS TotalEmployees,
    SUM(CASE WHEN Salary >= 85000 THEN 1 ELSE 0 END) AS HighEarners,
    SUM(CASE WHEN Salary <  85000 THEN 1 ELSE 0 END) AS LowEarners
FROM Employees
GROUP BY Department
```
**Key:** CASE stops at first match — no need to repeat the upper bound in `ELSE`.

## P5b — Salary Label Per Employee
**Concept:** CASE in SELECT

```sql
SELECT EmpName, Salary,
    CASE
        WHEN Salary >= 85000 THEN 'High'
        WHEN Salary >= 65000 THEN 'Mid'
        ELSE 'Low'
    END AS SalaryBand
FROM Employees
```

## P5c — Band Summary
**Concept:** CASE in GROUP BY + ORDER BY

```sql
SELECT
    CASE
        WHEN Salary >= 85000 THEN 'High'
        WHEN Salary >= 65000 THEN 'Mid'
        ELSE 'Low'
    END AS SalaryBand,
    COUNT(1) AS TotalEmployees
FROM Employees
GROUP BY
    CASE
        WHEN Salary >= 85000 THEN 'High'
        WHEN Salary >= 65000 THEN 'Mid'
        ELSE 'Low'
    END
ORDER BY
    CASE
        WHEN Salary >= 85000 THEN 1
        WHEN Salary >= 65000 THEN 2
        ELSE 3
    END
```
**Key:** Anything valid in SELECT is valid in GROUP BY, including CASE expressions.

## P6 — Department Salary Report (with JOIN)
**Concept:** RIGHT JOIN + NULL-safe COUNT

```sql
SELECT d.DeptName,
    COUNT(e.EmpID) AS TotalEmployees,
    CAST(ISNULL(AVG(CAST(e.Salary AS DECIMAL(10,2))), 0) AS DECIMAL(10,2)) AS AvgSalary
FROM Employees e
RIGHT JOIN Departments d ON e.DeptID = d.DeptID
GROUP BY d.DeptName
```
**Key:** `COUNT(EmpID)` not `COUNT(1)` — when RIGHT JOIN produces NULLs (Marketing has 0 employees), COUNT(1) gives 1 instead of 0.

## P7 — Location Salary Report
**Concept:** WHERE + JOIN + HAVING

```sql
SELECT d.DeptName, d.Location,
    COUNT(1) AS TotalEmployees,
    CAST(AVG(CAST(e.Salary AS DECIMAL(10,2))) AS DECIMAL(10,2)) AS AvgSalary
FROM Employees e
INNER JOIN Departments d ON e.DeptID = d.DeptID
WHERE d.Location = 'Pune'
GROUP BY d.DeptName, d.Location
HAVING AVG(e.Salary) > 80000
```

## P8 — Above Average Earners
**Concept:** Subquery in WHERE

```sql
SELECT EmpName, Department, Salary
FROM Employees
WHERE Salary > (SELECT AVG(Salary) FROM Employees)
ORDER BY Salary DESC
```
**Performance note:** Table scanned twice. Window function alternative (single scan):
```sql
SELECT EmpName, Department, Salary
FROM (
    SELECT *, AVG(Salary) OVER () AS CompanyAvg
    FROM Employees
) t
WHERE Salary > CompanyAvg
ORDER BY Salary DESC
```

## P9 — Above Average By Department
**Concept:** CTE + JOIN

```sql
WITH DeptAvg AS (
    SELECT Department,
        CAST(AVG(CAST(Salary AS DECIMAL(10,2))) AS DECIMAL(10,2)) AS AvgSalary
    FROM Employees
    GROUP BY Department
)
SELECT e.EmpName, e.Department, e.Salary, d.AvgSalary AS DeptAvgSalary
FROM Employees e
INNER JOIN DeptAvg d
    ON e.Department = d.Department
    AND e.Salary > d.AvgSalary
ORDER BY e.Department, e.Salary DESC
```

## P10 — Dept vs Company Comparison
**Concept:** Chained CTEs + implicit cross join

```sql
WITH CompanyAvg AS (
    SELECT AVG(CAST(Salary AS DECIMAL(10,2))) AS CompanyAvg
    FROM Employees
),
DeptAvg AS (
    SELECT Department,
        AVG(CAST(Salary AS DECIMAL(10,2))) AS DeptAvg
    FROM Employees
    GROUP BY Department
)
SELECT
    d.Department,
    CAST(d.DeptAvg    AS DECIMAL(10,2)) AS DeptAvg,
    CAST(c.CompanyAvg AS DECIMAL(10,2)) AS CompanyAvg,
    CAST(d.DeptAvg - c.CompanyAvg AS DECIMAL(10,2)) AS Difference,
    CASE WHEN d.DeptAvg > c.CompanyAvg THEN 'Above' ELSE 'Below' END AS Label
FROM DeptAvg d, CompanyAvg c
ORDER BY Difference DESC
```
**Key:** `FROM DeptAvg d, CompanyAvg c` — CompanyAvg is a single-row CTE, comma join works here.
